# Job-Prep-Interview-Rehearsal
A lightweight, web application for practicing behavioral and technical questions for a mock job interview using the STAR method, featuring a built-in timer and local scratchpad.

🔒 100% Private: No backend servers, no user accounts, and no cloud storage. Notes are kept temporarily in memory and disappear immediately upon page refresh, clearing the cache, or closing the window.

STAR Method Framework: Structured prompts to help users articulate behavioral answers using Situation, Task, Action, and Result.

Built-In Pacing Timer: Helps candidates practice concise, well-timed responses.

Smart Closing Questions: Curated questions for candidates to ask interviewers to gauge culture, expectations, and next steps.
